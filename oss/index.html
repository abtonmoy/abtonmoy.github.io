Things I've released & contributed

Nearly everything I build ends up public: weights, training code, evaluation harnesses, and the results that did not work. This page collects the released artifacts, the packages on PyPI, and the patches I've sent to other people's projects.

01 : Released models

  • fusion-embedding

    open weights · two generations

    A multimodal embedding family mapping text, image, video, audio, thermal, inertial motion and touch into one vector space. Two architecture generations are released, the first a trained connector and the second adding modality-gated deep adapters. Both are on the MTEB and MAEB leaderboards.

    weights github paper

  • Tactus & Tactus Mat

    touch · pressure arrays

    Open-vocabulary object recognition from pressure alone. 0.77 top-1 and 0.94 top-3 on the MIT STAG benchmark against the dataset authors' own supervised CNN at 0.76, and a second profile for body pressure mats at 0.957 top-1 across 17 in-bed postures. Both ship runnable notebooks and the full evaluation.

    tactus tactus mat

  • Ember & Tremor

    thermal · inertial motion

    Ember is a thermal sense pack that lifts thermal-to-text retrieval from 0.224 to 0.785 while leaving every non-thermal output bit-for-bit unchanged. Tremor reads body-worn and robot accelerometers as language, and ships a head specialized for the Unitree G1 humanoid.

    ember tremor

02 : Packages

  • engram-robomem

    Apache-2.0 · PyPI

    The memory layer for physical AI. Indexes a robot's video, audio, motion and touch into one embedding space on a shared clock and answers questions in plain language, including temporal reasoning that retrieval alone cannot do.

    github pypi demo

  • efferent

    Apache-2.0 · PyPI

    Universal ONNX policy deployment. Binds a trained control policy to a robot by joint name rather than by hand-maintained index arrays, with a pre-flight doctor that probes the network for permuted joint order, frame errors, missing scales and dead command dimensions before the robot moves.

    github pypi

  • semantic-sentry

    library · research code

    Model-agnostic detection of semantic drift in embedding spaces. Implements CKA, neighborhood preservation and isotropy diagnostics, plus the controls and pre-registrations behind the BlackboxNLP submission.

    github

03 : Merged into other projects

  • verl

    RL post-training · 3 merged

    Three fixes to the HybridFlow RL post-training framework. The critic value loss was normalized per micro-batch rather than over the global mini-batch, so the accumulated critic gradient was inflated by the micro-batch count and changed whenever that count did. Separately, the multi-turn tool agent loop dropped the chat template's turn separator at turn boundaries, and the fix for it needed a follow-up once multimodal processors turned out to reject the bare-string probe used to derive that separator.

    #6957 #6921 #6937

  • NVIDIA NeMo · Emerging-Optimizers

    optimizer research · 3 merged

    Added the left-spectral counterpart to the existing polargrad orthogonalization, then consolidated the left and right variants into a single function after review. Later added a composable row-norm update rule that scales each row of the momentum to unit norm, with optional centering to match the polargrad functions.

    #247 #248 #253

  • voxel51 / fiftyone

    visual AI · 1 merged

    Documented two behaviours of the similarity index that are easy to hit and hard to debug afterwards: a text-searchable index must name its model rather than hold an instance, and precomputed embeddings can be combined with a model name, which is the only path for data whose embeddings cannot come from a sample's media. Found while building a zoo model source that puts sensor streams into a text space.

    pr #8171 issue #3961

  • embeddings-benchmark · mteb

    benchmarks · 10 merged

    Added both generations of the fusion-embedding family to the MTEB model registry and submitted results across the text, audio and video benchmark boards, including a torchcodec-native video path adopted after maintainer review, plus revision pins and citation updates as the models moved.

    mteb #4909 #4952 results #601

  • qdrant

    vector database · 1 merged

    Added Fusion Embedding 2 to Qdrant's embeddings integrations, so the family appears alongside the other supported providers in their documentation.

    pr #2548

  • fortress & tilion

    tooling · 8 merged

    Test suites for the Node SDK and the patch-set checker, a CI pipeline with a patch-integrity linter and a markdown link and badge checker, a release-asset validator, and a real ad-blocking mode for the browser engine built on adblock-rust with EasyList.

    fortress

04 : Open & in review

  • Liger-Kernel

    Triton kernels · in review

    Native Sparse Attention as a Triton-kernel-backed module, implementing the natively-trainable sparse attention built for grouped-query models, which closes a standing request on the repo. A second patch adds the missing nn.Module wrapper for the existing attention-residuals op, completing that op's artifact set.

    nsa kernels attnres wrapper

  • vllm-omni

    distributed inference · in review

    Distributed tiled VAE encode for two diffusion pipelines, the encode-side counterpart to the existing decode paths: one for LTX-2 video and one for the Qwen-Image edit pipelines, each following the recipe already established for Wan.

    ltx-2 qwen-image edit

  • lerobot, chroma, theia, rl_sar

    robotics & retrieval · in review

    A rotation-vector canonicalization fix in LeRobot's action interpolator; a Fusion Embedding function for Chroma; C-RADIO added as a teacher in Theia; and a frame fix in rl_sar, where the Lite3 angular velocity was read in the world frame where the policy expects the body frame, which is the same bug class the Efferent doctor exists to catch.

    lerobot chroma theia rl_sar

05 : How I release

Weights come with the evaluation code that produced their numbers, the recipe needed to retrain them, and the levers that failed. Claims are scoped to what was measured: means across seeds rather than best runs, and held-out splits stated plainly. When a result did not reproduce, that is written down too, because the negative results have been more useful to me than most of the positive ones.

Things I've released & contributed

Nearly everything I build ends up public: weights, training code, evaluation harnesses, and the results that did not work. This page collects the released artifacts, the packages on PyPI, and the patches I've sent to other people's projects.

01 : Released models

  • fusion-embedding

    open weights · two generations

    A multimodal embedding family mapping text, image, video, audio, thermal, inertial motion and touch into one vector space. Two architecture generations are released, the first a trained connector and the second adding modality-gated deep adapters. Both are on the MTEB and MAEB leaderboards.

    weights github paper

  • Tactus & Tactus Mat

    touch · pressure arrays

    Open-vocabulary object recognition from pressure alone. 0.77 top-1 and 0.94 top-3 on the MIT STAG benchmark against the dataset authors' own supervised CNN at 0.76, and a second profile for body pressure mats at 0.957 top-1 across 17 in-bed postures. Both ship runnable notebooks and the full evaluation.

    tactus tactus mat

  • Ember & Tremor

    thermal · inertial motion

    Ember is a thermal sense pack that lifts thermal-to-text retrieval from 0.224 to 0.785 while leaving every non-thermal output bit-for-bit unchanged. Tremor reads body-worn and robot accelerometers as language, and ships a head specialized for the Unitree G1 humanoid.

    ember tremor

02 : Packages

  • engram-robomem

    Apache-2.0 · PyPI

    The memory layer for physical AI. Indexes a robot's video, audio, motion and touch into one embedding space on a shared clock and answers questions in plain language, including temporal reasoning that retrieval alone cannot do.

    github pypi demo

  • efferent

    Apache-2.0 · PyPI

    Universal ONNX policy deployment. Binds a trained control policy to a robot by joint name rather than by hand-maintained index arrays, with a pre-flight doctor that probes the network for permuted joint order, frame errors, missing scales and dead command dimensions before the robot moves.

    github pypi

  • semantic-sentry

    library · research code

    Model-agnostic detection of semantic drift in embedding spaces. Implements CKA, neighborhood preservation and isotropy diagnostics, plus the controls and pre-registrations behind the BlackboxNLP submission.

    github

03 : Contributions to other projects

  • voxel51 / fiftyone

    2026 · merged

    Documented two behaviours of the similarity index that are easy to hit and hard to debug afterwards: a text-searchable index must name its model rather than hold an instance, and precomputed embeddings can be combined with a model name, which is the only path for data whose embeddings cannot come from a sample's media. Found while building a zoo model source that puts sensor streams into a text space.

    pr #8171 issue #3961

  • embeddings-benchmark / mteb

    2026 · merged

    Added both generations of the fusion-embedding family to the MTEB model registry and submitted results across the audio and video benchmark boards, including a torchcodec-native video path adopted after maintainer review.

    github

04 : How I release

Weights come with the evaluation code that produced their numbers, the recipe needed to retrain them, and the levers that failed. Claims are scoped to what was measured: means across seeds rather than best runs, and held-out splits stated plainly. When a result did not reproduce, that is written down too, because the negative results have been more useful to me than most of the positive ones.

03 : Selected Projects see all →

  • Fusion Embedding & the sense packs

    2026 · open weights

    One embedding space for text, image, video, audio, thermal, motion and touch. The base model stays frozen and each new sense arrives as a separately loadable pack, so existing embeddings stay bit-for-bit valid and gaining a modality never costs a re-index. Tactus reads a 32×32 pressure glove at 0.77 top-1 / 0.94 top-3 on the MIT STAG benchmark, where the dataset authors' own supervised CNN reached 0.76, while answering open-vocabulary text queries rather than a fixed label set. Tactus Mat does the same for a hospital bed mat at 0.957 top-1 across 17 postures, Ember lifts thermal-to-text retrieval from 0.224 to 0.785, and Tremor reads inertial motion. On the MTEB and MAEB leaderboards.

  • Engram

    2026 · pip install engram-robomem

    The memory layer for physical AI. Index a robot's video, audio, motion and touch into one embedding space on a shared clock, then ask questions about it in plain language, including the temporal reasoning retrieval alone cannot do: when did it last lose grip, what was it holding before the shelf fell. Apache-2.0.

  • Efferent

    2026 · pip install efferent

    Universal ONNX policy deployment: any trained control policy, any robot, bound by joint name instead of the hand-maintained index arrays every deployment repo warns about. A pre-flight doctor probes the network itself for permuted joint order, world-versus- body frame errors, missing scale factors and dead command dims, so the bugs that make robots fall are caught before anything moves. Apache-2.0.

  • SemanticSentry

    2025 · library

    Open-source library accompanying our BlackboxNLP submission. A model-agnostic framework for detecting semantic drift in embedding spaces — quantifying geometric transformations induced by fine-tuning, quantization, and LoRA updates without requiring labeled evaluation data. Combines CKA for global structure, NPS for local neighborhoods, and Isotropy for spectral geometry, accelerated by FAISS nearest-neighbor search and surfaced through W&B and MLflow hooks.

  • Fusion Embedding & the sense packs

    2026 · open weights · arXiv

    One embedding space for text, image, video, audio, thermal, inertial motion and touch. The base model stays frozen and each new sense arrives as a separately loadable pack, so existing embeddings stay bit-for-bit valid and gaining a modality never costs a re-index. In practice a sensor nobody has modeled before becomes a small trained head and an afternoon on one GPU. Released on the MTEB and MAEB leaderboards with the training recipes, the evaluation code, and the negative results.

  • Tactus & Tactus Mat

    2026 · touch

    Object recognition from pressure alone. Tactus reads a 32×32 resistive glove and answers text queries rather than a fixed label set, reaching 0.77 top-1 and 0.94 top-3 on the MIT STAG benchmark where the dataset authors' own supervised CNN reached 0.76. Tactus Mat is the same recipe retrained for a 64×32 hospital bed mat, answering 17 in-bed postures at 0.957 top-1 on held-out subjects, and 0.882 against coarse phrases it never saw during training. Both ship with notebooks that run on public data.

  • Engram

    2026 · pip install engram-robomem

    The memory layer for physical AI. Index a robot's video, audio, motion and touch into one embedding space on a shared clock, then ask questions in plain language, including the temporal reasoning that retrieval alone cannot do: when did it last lose grip, what was it holding before the shelf fell. Apache-2.0, on PyPI, with a live demo over a real humanoid session.

  • Efferent

    2026 · pip install efferent

    Universal ONNX policy deployment: any trained control policy on any robot, bound by joint name instead of the hand-maintained index arrays that every deployment repo warns about. A pre-flight doctor probes the network itself for permuted joint order, world-versus-body frame errors, missing scale factors and dead command dimensions, so the bug class that makes robots fall is caught before anything moves. Apache-2.0.
